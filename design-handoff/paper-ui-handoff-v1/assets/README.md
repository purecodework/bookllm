# 素材使用说明

## 角色 — 只使用最后一版

`roles/translator.png`、`proofreader.png`、`linguist.png`、`editor.png` 是透明背景 PNG 母版，均为 1254×1254。译者为修订后的低头读书人物；主编是圆框眼镜与弯柄烟斗。不要从以前的 ZIP 混入 `*-abstract.png` 或旧版写实角色。

`roles/ui/` 提供每位角色的 128/256/384 px 输出，文件名 @1x/@2x/@3x 对应参考的 128 pt 图像容器；实际控件内按 88–96 pt 高度等比 contain，可按平台资源系统选择密度。宽高不能拉伸，不能裁掉书页和烟斗。空白属于原图构图的一部分。

这些不是 SVG，也没有分层笔画/动效路径。不要把母版复制成 .svg 扩展名；不要在无需用户同意时自动重绘或矢量化。显示为墨色开放轮廓，不加头像底圈、投影、填色或烟雾。

## 纸纹

`paper/paper-texture.png` 是原始高分辨率材质；`paper/paper-tile.jpg` 是原交互稿中实际使用的轻量平铺片。首选 tile，alpha/混合模式见 tokens。材质始终在文字下方静止，正式 App 缓存一次，不为每个书目重复解码原图。

## 示例封面

`demo-covers/` 是对话生成的《远山来信》和《雨后的花园》示例封面，包含原图与轻量 -ui.webp。只用于预览/测试；真实文稿用它自己的可提取原始封面。没有封面时使用已有排版占位，不擅自用示例覆盖。

## 文件与来源

角色来自本对话最后一版 `paper-reader-prototype.zip` 中 `public/assets/roles/*-sketch.png`；不是根据描述临时重画。紙纹、封面也来自该包。第一张阅读参考来自本对话 `澄纸阅读_风起时.png`。

本包不包含字体文件、API key、真实用户文稿、支付数据或生产代码。字体使用平台已许可的系统字体或项目已有资源。本文件不对图像作独家权利或额外版权保证；正式品牌使用沿用项目自身的素材审核流程。
